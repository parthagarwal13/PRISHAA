PRISHAA Razorpay Standard Web Checkout

Already integrated in the codebase:
- POST /api/payment/create-order
- POST /api/payment/verify
- POST /api/payment/failed
- Standard Checkout script on user page
- Server-side HMAC-SHA256 signature verification
- Server-side Razorpay payment-status check before marking the Neon order Paid
- Minimum order amount validation of ₹1.00 (100 paise)

Local setup:
1. Run: npm install
2. Create root .env (do NOT commit it) and add:
   RAZORPAY_KEY_ID=rzp_test_...
   RAZORPAY_KEY_SECRET=...
   RAZORPAY_WEBHOOK_SECRET=...
3. Keep DATABASE_URL pointing to your Neon PostgreSQL database.
4. Run: npm start
5. Open the site, add a product to cart, open checkout, and click Pay Securely Online.

Production:
- Add the same environment variables in Vercel/Render.
- Use Live Mode keys only after Razorpay onboarding/KYC and final testing.
- Do not put RAZORPAY_KEY_SECRET in frontend code or GitHub.
